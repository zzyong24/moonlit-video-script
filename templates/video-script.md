# 视频脚本与分镜模板（v1.5）

> 服务于作者原意表达与下游零返工交接。时长由表达密度和用户要求决定；开场可用处境、具体问题、观察或结果引入，不强制制造痛点或反转。

## 文件名格式

```text
MMDDHHMM-[中文主题]-视频脚本.md
```

仅 `html_explainer` / `avatar_explainer` 等需送 TTS 合成的模式，按需另存纯正文副本 `MMDDHHMM-[中文主题]-AI旁白稿.md`。

---

## 模板 A：成片模式（`talking_head_broll` / `html_explainer` / `avatar_explainer`）

```markdown
# [具体主题标题] · 视频脚本

- 作品：`W-YYYYMMDD-NNN`
- status：`draft`（待作者确认；确认后改为 `confirmed` 并运行 guoshen `script` 阶段审核）
- production_mode：`talking_head_broll` | `html_explainer` | `avatar_explainer`（只填最终选定的一项）
- 目标平台：待定 / 抖音、视频号、B站、小红书（同发共用母版）
- 画幅：`16:9`（默认；若选 `9:16` 须注明用户明确指令或竖屏源素材依据）
- 预估时长：约 X 分 X 秒（预估预算，实录或配音后以真实主音频和同版 SRT 为唯一时钟）
- 核心命题与主体：[一句话写清主角是什么；贯穿案例服务于主体机制，不喧宾夺主]
- 观众继续看的收获：[看完能分清、理解、判断或照着做哪件事]
- 片尾 CTA 来源：[本期最新确认原话 / `maintenance/video-cta-default.json` 版本号 / 自然收尾无 CTA]
- script 阶段三审：`pending（初稿不强审）` | `passed（回执路径，unreviewed: audio/visuals/cover/nativeSettings/platformCoverCrop）`

## 章节推进

1. `P01｜[具体对象 + 问题/处境]`：
2. `P02｜[具体对象 + 判断/动作]`：
3. `P03｜[具体对象 + 证据/机制]`：
4. `P04｜[具体对象 + 边界/收束]`：

> 注：章节标题将直接进入横版顶部导航条，严禁单独写“引言”“背景”“Agent 时代”“行动”“总结”。
```

## 模板 B：手动翻页与自由画布模式（`html_presentation` / `excalidraw_explainer`）

> 适用于 `moonlit-ppt-html` 与 `moonlit-explainer-canvas`。**不生成**秒级字幕时间轴、TTS 报价、SRT 或平台视频封面要求；排练估时仅供参考。

```markdown
# [具体主题标题] · 演示讲解稿与分页职责

- 作品：`W-YYYYMMDD-NNN`
- status：`draft` | `confirmed`
- production_mode：`html_presentation` | `excalidraw_explainer`
- 画幅：`16:9`（HTML PPT 固定） | `自由缩放无限画布`（Excalidraw）
- 核心命题与主体：[一句话明确整场演示围绕的主体机制]
- 观众收获：[听完能看懂什么结构或带走什么动作]
- script 阶段三审：`pending` | `passed`

## 分页 / 分区职责与现场动作表

| 页/区编号 | 页面具象标题 | 单一解释任务与可见逻辑结构 | 现场动作提示（不朗读） | 素材与来源状态 |
|---|---|---|---|---|
| S01 / N01 | [直接回答观众问题的标题] | 全景关系图：标明入口、核心环节、人工决策位与结果去向 | 先指顶层主链路，再停在本次要拆的卡点节点 | 架构事实：`...`；配图复用/待制 `planned` |
| S02 / N02 | [具体动作或机制判断] | 对照图或真实截图局部（`figure[data-image-id]`） | 切开真实文件看关键字段，讲完按快捷键返回主图 | 真实文件已读；截图 `planned` |

## 独立讲解净稿
```
