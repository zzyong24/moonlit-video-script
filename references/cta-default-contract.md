# 账号默认 CTA 配置契约

CTA 的文案、适用范围和优先级归本 Skill；录音、字幕时间映射与混音交当前制作 Skill。账号偏好与私人素材留工作区，不打包到 Skill。

## 读取与选择

1. 从当前 canonical workspace 读取 `maintenance/video-cta-default.json`（配置位置，不是 Skill 相对文件）；若工程明确提供其他配置入口，按该入口解析。
2. 先检查本期最新逐字确认，再读取适用的账号默认，最后才查历史已确认素材。新默认明确选定的素材优先于旧历史候选。没有配置时不猜路径、话术或用户认可；只在当前确认支持下回退，缺口明确列出。
3. 用户明确“以后就用这个”才更新长期默认；一次录制、单期纠错或技术通过不自动晋升。记录确认原话、日期及范围，不改写历史作品或发布凭证。

## 最小配置与交接

- `schemaVersion`、`version`、`status`、`effectiveFrom`、`scope`、`confirmation`：区分用户确认、技术状态和适用范围。
- `text.zh`、`text.en`：准确中文与对应英文。英文为辅助译文，不能加入收益保证；译文尚未独立认可时明确记录。
- `asset.workId`、`asset.artifact`、`asset.media`、`asset.sha256`：从作品权威 artifact 解引用当前源素材，核路径与 hash，不仅按文件名找旧版。
- `captions`：原时钟的可编辑分句、中英同窗字幕与词级数据引用；实际接入时间线后由剪点、速率和起始帧重映射，不照抄源秒数当成片时间。
- `reuse`、`verification`、`pendingTests`：原声/动作保留、倍速状态、媒体验证与未完成检查。素材批准不意味着每次接入的合成、混音或字幕已经通过。

脚本资产需求引用上述配置版本和素材；制作端回读字幕原文、英文、共窗与原声。旧模板、ASR、字幕重建不得覆盖确认文本；更改剪点或速度时连同跟读层一起重映射。缺媒体或字幕就报告缺口，不静音、换 TTS 或自创 CTA 来伪装完成。

## 边界回归

- 新默认 + 无本期覆盖：选新素材与新字幕，不取旧 Vibe Coding 模板。
- 新默认 + 本期明确另一结尾：只覆盖本期，不改账号默认。
- 用户只改本期字幕：不改默认、不替换录音。
- 已发布的旧稿：保留原文件和发布凭证；改默认不授权重剪、重新发布或付费生成。
- 缺配置或素材：明确降级/待补；配置不是未来发布、支付或外部消息的长期授权。
